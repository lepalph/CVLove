# Audit qualité CVLove (lecture seule)

**Ce que fait le dépôt :** CV 100 % local (Vite, React 19, TS, react-pdf, pdf.js, zustand persisté en localStorage), 12 mises en page x 3 styles = 36 modèles, 7 langues. Charge supposée : un seul utilisateur, navigateur, y compris téléphone bas de gamme.
**Mesuré :** `pnpm build` OK (tsc propre), `pnpm test` 23/23. Bundles : index 333 ko (106 ko gzip), pdf.js 430 ko (129 gz), react-pdf 1,2 Mo (443 gz), worker pdf.js 1,26 Mo (375 gz), 12 layouts de 3 à 5 ko. Polices 3,7 Mo (chargées à la demande). i18n : ui 87 clés, home 31, v2 51, guide 30, x 7 langues : 0 clé manquante, 0 écart de `{n}` (script `/tmp/cvl/i18n.ts`) ; les types `Record<Lang,…>` l'imposent déjà. Seules différences : cognats allemands/italiens normaux.

## À corriger d'abord
1. **Quota localStorage plein = perte silencieuse** (`src/store.ts:127-145`). Le stockage utilise `setItem` sans try/catch. Vérifié : `update()` lève `QuotaExceededError` (état en mémoire gardé, rien écrit), l'utilisateur continue à taper puis perd tout au rechargement. Les photos (JPEG 512 px, ~100-200 ko en base64, recopiées par « dupliquer ») et la clé `cvlove:v1` laissée en place (`:136`, doublon de la photo) accélèrent la saturation. Correctif : envelopper `setItem` dans try/catch + bandeau « stockage plein, exportez en JSON » ; supprimer `cvlove:v1` après migration réussie.
2. **Données corrompues ou import mal formé = écran blanc permanent** (`store.ts:133-142`, `model/cv.ts:103`, `model/documents.ts:30-38`). `getItem` avale le JSON invalide (renvoie null) puis la première frappe écrase l'original sans copie. Un JSON valide mais de mauvaise forme (`documents:"x"`, section sans `items`, `name` non texte) passe `isCVData` (vérifie seulement `personal`/`sections`), est écrit dans localStorage, plante au rendu, et replante à chaque rechargement. Aucun error boundary dans `App.tsx`. Correctif : valider `items`/`name`/`design` dans `parseImport` et sur l'état relu (sinon repartir du CV d'exemple en gardant la copie brute dans `cvlove:corrupt`), plus un error boundary avec « Réinitialiser ».
3. **Design importé non validé** (`documents.ts:35`, `templates/shared.tsx:26,33,40`, `pdf/fontPairs.ts:23`). `{...DEFAULT_DESIGN, ...x.design}` accepte `accent:"rouge"` (tint/shade donnent `#NaN…`), `fontPair` inconnu (`FONT_PAIR_DEFS[pair]` undefined, TypeError), `pageSize` ou `fontScale` absurdes. Même crash que 2. Correctif : une fonction `cleanDesign` qui garde la valeur seulement si elle est dans les listes (`FONT_PAIRS`, `MARGINS`…), regex `#rrggbb`, nombres bornés.
4. **Import JSON inaccessible au clavier** (`ui/Form.tsx:170-171`). `<input hidden>` + `<label>` : pas focusable, WCAG 2.1.1. `Documents.tsx` fait bien (bouton + ref). Correctif : même schéma (bouton qui appelle `ref.click()`).
5. **`check:pdf` vert alors que rien n'est testé** (`scripts/check-pdf.ts:46-47`). Si le registre est vide (glob cassé, `meta` non reconnu), il affiche `0/0 rendus valides` et sort en 0. Aucun contrôle non plus que `meta.id` = nom du fichier, des ids uniques, 3 styles (`templates/registry.ts:4`). Correctif : `if (!ok) exit(1)` et dans `buildTemplates` lever une erreur si `id !== nom de fichier` ou id en double.

## À améliorer
6. **Persistance synchrone à chaque frappe** (`store.ts:53,127`). Chaque caractère sérialise tous les documents (photos comprises) dans localStorage sur le fil principal. Correctif : `setItem` avec délai (500 ms) + écriture immédiate sur `pagehide`.
7. **Aperçu rendu quand il est caché** (`ui/Editor.tsx:68-71`). Sur mobile, l'onglet « Édition » masque l'aperçu (`hidden`) mais `PdfCanvas` re-rend tout le PDF à chaque pause de frappe (react-pdf est sur le fil principal, 1 à 3 s sur téléphone modeste). Correctif : ne monter `PdfCanvas` que si `tab==='preview'` ou écran large (`matchMedia`).
8. **Mémoire canvas** (`pdf/PdfCanvas.tsx:28,44`). `dpr` jusqu'à 2 x largeur 736 px x jusqu'à 20 pages = ~12 Mo par page (double pendant l'échange des tampons) ; iOS plafonne autour de 256 Mo. Correctif : `dpr` max 1,5 sur mobile et `maxPages` 4 dans l'éditeur (le téléchargement garde tout).
9. **Accueil : 2,3 Mo de JS avant le premier aperçu** (`ui/Home.tsx` hero `SamplePage eager`). La page de présentation charge react-pdf + pdf.js + worker (~950 ko gzip) et une police TTF pour afficher une image. Correctif : image statique (PNG/WebP déjà produits par check:pdf dans `out/`) pour le hero, rendu PDF seulement à l'ouverture de l'éditeur ou du catalogue.
10. **36 vignettes sans file d'attente** (`ui/SamplePage.tsx:10-17`). Un défilement rapide lance des dizaines de rendus react-pdf en parallèle (aucune annulation possible, `PdfCanvas` annule seulement pdf.js) ; en outre une promesse rejetée (réseau coupé au chargement d'un chunk) reste dans `cache` pour toujours : plus de réessai. Correctif : file à 1-2 rendus simultanés ; `p.catch(() => cache.delete(key))`.
11. **Téléchargement sans message d'erreur** (`Editor.tsx:27-38`, copie dans `LetterEditor.tsx:37`). `try/finally` sans `catch` : en cas d'échec, rejet non géré, le bouton se réactive sans rien dire. Même chose pour `onPhoto` (`Form.tsx:64`, HEIC non lisible par `createImageBitmap`). Correctif : `catch` -> `setError(t.previewError)`.
12. **Code dupliqué entre les 12 mises en page** (`templates/layouts/*.tsx`). `const MUTED` (3 valeurs différentes) x12 ; rendu profil `fixBidi(items…join('\n'))` et intérêts `join('  ·  ')` recopiés (12 fichiers) ; chaque layout refait `entry/body/title`. Correctif minimal : exporter `MUTED`, `profileText`, `interestsText` depuis `shared.tsx`. Gain : ~60-80 lignes ; ne pas fusionner plus (les variantes diffèrent vraiment).
13. **Accueil sans SEO exploitable** (`index.html`). Pas de `og:*`, `twitter:*`, `canonical`, `theme-color` ; `<html lang="fr">` figé (changé par JS seulement) ; corps vide sans JS (pas de `<noscript>`) ; routes en `#/` donc une seule URL indexable. Titre unique "CVLove" sur les 3 vues (`App.tsx:23`), WCAG 2.4.2. Correctif : meta og/description/canonical (URL de prod à fournir), `<noscript>` d'une phrase, `document.title` selon la vue.
14. **Contrastes** (`src/index.css:11-12`). Bordure des champs `--c-edge #d4d4d4` sur blanc = 1,48:1 (WCAG 1.4.11 demande 3:1) ; mode sombre 1,74:1. `--c-danger #ee0000` en petit texte = 4,34:1 (<4,5). Correctif : `--c-edge` ~ `#8c8c8c` (clair) / `#6b6b6b` (sombre), `--c-danger` `#d60000`.
15. **Aperçu canvas pour lecteur d'écran** (`Editor.tsx:70`, `SamplePage.tsx`). `aria-label` sur un `div` sans rôle est ignoré ; les `<canvas>` n'ont aucun texte. Correctif : conteneur `role="img"` + `aria-label` (nom, titre, nombre de sections) pour l'aperçu ; `aria-hidden` sur les vignettes (le nom du modèle est déjà dans le bouton/titre).
16. **Pastilles de couleur nommées par leur hex** (`DesignPanel.tsx:102`) : le lecteur d'écran lit « dièse c 2 4 1 0 c ». Correctif : noms traduits dans `v2.ts` (7 mots x 7 langues) ou `aria-label={`${t.accent} ${i+1}`}`.
17. **Onglets Édition/Aperçu incomplets** (`Editor.tsx:53`). `role=tablist` sans `tabpanel`, `aria-controls` ni flèches clavier. Correctif : soit les compléter, soit utiliser deux boutons `aria-pressed` (comme `Seg`), plus simple.

## Tests manquants (code risqué)
18. Aucun test sur : stockage plein/corrompu/migration depuis un `cvlove:v1` invalide, `parseImport` avec design ou sections invalides, `tint/shade/onAccent` (accent court ou invalide), registre (ids uniques, `meta` extrait par regex fragile `vite-layout-meta.ts:15`), `buildTemplates`. Les 23 tests existants couvrent le chemin normal. L'e2e (`tests/e2e/cvlove.spec.ts`, 12 scénarios) est bon mais pas de CI (`.github` absent) ; `.gitignore` contient `e2e`, qui ignorerait tout nouveau fichier de `tests/e2e/`. Correctif : 6 tests vitest (un par cas ci-dessus), retirer `e2e` du `.gitignore`, un workflow `pnpm build && pnpm test`.

## Mineurs (non détaillés : 4)
Focus non rendu après renommage (`Documents.tsx`) ; deux onglets ouverts s'écrasent (pas d'événement `storage`) ; `download()` refait le PDF au lieu de réutiliser les octets de l'aperçu ; PDF arabe non extractible/ATS (limite connue, documentée dans `fontPairs.ts`).

**Verdict :** corriger 1, 2, 3 (perte de données et écran blanc) puis 4 et 5 ; les perfs mobiles (7, 8, 9) ensuite.
**Lean :** -70 lignes (point 12), 0 dépendance.
**Non lu :** `Guided.tsx` (fin), `letter*`/`LetterEditor` (en cours par un autre agent), corps des 12 layouts (seulement `classique` en entier + grep transversal), pas de test sur vrai téléphone. `pnpm build` a régénéré `dist/` (ignoré par git).
